## A. 서버·데이터 (가장 큰 작업)
- [ ] 🤖 데이터 저장: 지금은 브라우저(localStorage)에만 저장 → 서버 DB로 이전 (요청서·제안·코인·결제신청·권한 기록)
- [ ] 🤖 모든 규칙을 서버에서 검증: 코인 차감·5곳 제한·중복 제안 금지·연락처 공개 권한(상담하기 선택 사무소만)·사무소 직원 초대 코드와 대표 승인 권한·접수 시점 산정 버전
- [ ] 🤖 48시간 미열람 자동 코인 반환 → 서버 예약 작업(스케줄러). 지금은 관리자 화면 "48시간 미열람 반환(시연)" 버튼
- [ ] 🤖 사진: 브라우저에 압축 저장 → 서버 파일 저장소 + 열람 권한
- [ ] 🧑 서버/DB 서비스 가입(예: Supabase·Vercel) 및 결제수단 등록

## B. 로그인·본인확인
- [ ] 🤖🧑 카카오 로그인: 지금은 가짜 계정("김건축 · 010-4821-7365") → 카카오 로그인 API. **전화번호 받으려면 카카오 비즈앱 전환 + 검수 필요(🧑 신청)**
- [ ] 🤖🧑 전화번호 인증: 지금은 인증번호 123456 고정 → 실제 문자 인증. **🧑 문자발송 서비스 계약(건당 약 10~20원)**
- [ ] 🤖 고객 개인 링크(kon.kr/r/xxxx): 지금은 예시 → 추측 불가 토큰 + 유효기간
- [ ] 🤖 사무소·관리자 로그인: 시연 비밀번호·바로 로그인 버튼 제거(`DEMO=false`), 서버 인증·권한으로 교체
- [ ] 🧑 도메인 구입·연결 (예: kon.kr 등)

## C. 알림 (카카오 알림톡 / 문자)
지금은 모두 화면 안 예시(토스트·로그)만 있음.
- [ ] 🧑 카카오 비즈니스 채널 개설 + 알림톡 템플릿 승인 신청, 발송대행사 계약
- [ ] 🤖 사무소에 "새 요청 도착(남은 자리 N)" 알림
- [ ] 🤖 고객에게 "요청 접수 / 제안 도착 + 개인 링크" 알림 (알림톡 실패 시 문자로 대체)
- [ ] 🤖 고객이 '상담하기' 누르면 해당 사무소에만 고객 이름·연락처 전달 알림
- [ ] 🤖 사무소 카카오톡 상담 연결: 지금은 토스트 → 각 사무소 카카오 채널 링크 입력·연결

## 현재 정책 (출시 때도 유지)
- 코인: 제안 시 차감 → 고객 열람 시 사용 확정 → 48시간 미열람 시 반환 / 열람 후 미선택은 반환 없음 / 반환 자리 재개방 없음
- 견적 요청은 지역과 관계없이 등록된 모든 사무소에 표시 (사무소가 골라서 제안) · 알림도 전체 발송
- 한 요청 최대 5곳, 같은 요청 중복 제안 불가
- 고객 이름·연락처는 '상담하기'를 누른 사무소에만 공개, 상담은 카카오톡으로만
- 코인 가격: 1코인 15,000 / 10코인 120,000 / 20코인 220,000 / 월정기 10코인 100,000 / 연간 1,000,000 (VAT 별도)
